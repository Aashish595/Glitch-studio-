# 🎬 Glitch Studio – VFX & Animation Portfolio

A cinematic portfolio website built for **Glitch Studio**, a professional VFX team specializing in **2D & 3D animation**, visual effects, and creative storytelling.

## ✨ Highlights
- High-end cinematic UI
- Smooth page transitions & animations
- Team and services showcase
- Optimized performance & SEO
- Responsive across all devices

## 🧰 Tech Stack
- Next.js
- Tailwind CSS
- Framer Motion
- GSAP
